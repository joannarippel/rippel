# Linux User and Permission Script

This script automates creating users, folders, and setting file permissions for a Linux exercise about users and file rights.

## How to use

1. Make the script executable:
   ```bash
   chmod +x user_permissions_script.sh
   ```
2. Run the script as root:
   ```bash
   sudo ./user_permissions_script.sh
   ```

## Note

- The script needs to be run with sudo because it creates users and changes permissions.
- Test it first on a safe system (like a virtual machine).
